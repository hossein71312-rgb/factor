# آسیا فاکتور — پروژه اندروید

این پروژه نسخه HTML فاکتور را داخل WebView اندروید اجرا می‌کند و در شروع، ویدئوی splash ارسالی به‌همراه یک ملودی کوتاه اختصاصی پخش می‌شود.

## ساخت APK با GitHub Actions
1. تمام محتویات این پوشه را در یک مخزن GitHub جدید بارگذاری کن.
2. از بخش **Actions**، گردش کار **Build Asia Factor APK** را انتخاب کن.
3. روی **Run workflow** بزن (یا تغییرات را به شاخه `main` ارسال کن).
4. پس از سبز شدن اجرا، در بخش **Artifacts** فایل `asia-factor-debug-apk` را دانلود کن.
5. فایل ZIP آرتیفکت را باز کن؛ `app-debug.apk` داخل آن است.

## نکته‌ها
- نسخه فعلی Debug است و برای نصب آزمایشی مناسب است؛ انتشار رسمی نیاز به امضای Release دارد.
- فاکتورها با localStorage وب‌ویو ذخیره می‌شوند؛ پاک‌کردن داده‌های برنامه یا حذف برنامه ممکن است آن‌ها را پاک کند. خروجی JSON را برای پشتیبان‌گیری نگه دار.
- کتابخانه‌های PDF در HTML فعلی از CDN بارگیری می‌شوند، بنابراین تولید PDF در اولین اجرا به اینترنت نیاز دارد.
- این محیط اجرای واقعی GitHub Actions یا نصب روی گوشی را انجام نداده است؛ ساخت APK پس از اجرای workflow در GitHub تأیید می‌شود.
